# SkillBridge
### Discover Opportunities. Understand Skills.

SkillBridge is an interactive career discovery website developed as part of a Web Technology university project. It aims to help university students explore virtual training opportunities and understand the skills associated with different career paths.

Rather than functioning as a complete recruitment platform, SkillBridge provides a simple, accessible, and informative experience that connects students with sample training opportunities and relevant skill requirements in one place.

## 📌 Project Overview

Many university students find it difficult to identify suitable training opportunities and understand which skills they need to develop before pursuing a particular career path.

SkillBridge addresses this challenge by organizing training opportunities and career-related skills into a clear, user-friendly website. Students can explore opportunities, search by field, review required skills, and discover areas for further learning.

## 🎯 Project Objectives

- Help students discover virtual training opportunities across different fields.
- Make opportunity information easier to explore and understand.
- Highlight the skills associated with different career paths.
- Provide search and filtering features for easier navigation.
- Demonstrate core web technologies through dynamic data handling and interactive interfaces.
- Create a consistent and responsive user experience.

## ✨ Key Features

### 1. Home Page
- Introduces the SkillBridge concept and its purpose.
- Highlights the main sections and features of the website.
- Provides clear navigation to opportunities and the skills guide.
- Displays dynamic information retrieved from an external API.

### 2. Opportunities Page
- Displays sample virtual training opportunities.
- Supports searching and filtering opportunities by career field.
- Presents opportunity details, descriptions, and required skills.
- Uses JSON to organize and retrieve demonstration data.

### 3. Skills Guide
- Organizes career-related skills into relevant categories.
- Helps students understand the skills associated with different fields.
- Uses XML as a structured data source.
- Reads and displays XML data using JavaScript.

## 🛠️ Technologies Used

- **HTML5** — Structuring website content and pages.
- **CSS3** — Styling, layouts, responsive design, and visual consistency.
- **JavaScript** — Interactive functionality, search, filtering, and data processing.
- **External API** — Retrieving and displaying dynamic data on the home page.
- **JSON** — Storing and organizing sample training opportunity data.
- **XML** — Structuring career-related skills data.

## ⚙️ How It Works

1. Students visit the home page to learn about SkillBridge and explore featured content.
2. They navigate to the Opportunities page to browse, search, and filter sample training opportunities.
3. They open the Skills Guide to explore skills associated with different career fields.
4. JavaScript processes data from the external API, JSON file, and XML file, depending on the page and its functionality.

## 🚀 Getting Started

### Prerequisites

- A modern web browser.
- A code editor such as Visual Studio Code.
- A local development server, such as the Live Server extension in Visual Studio Code.

### Installation

1. Clone or download the project repository.
2. Open the project folder in your code editor.
3. Start a local development server from the project directory.
4. Open the website through the local server URL.

A local server is recommended because browsers may restrict JavaScript access to local JSON and XML files when pages are opened directly using the `file://` protocol.

### API Configuration

The home page uses an external API to retrieve dynamic data.

Configure the API endpoint in the appropriate JavaScript file and ensure that the application handles loading, successful responses, empty results, and connection errors.

API availability and cross-origin restrictions may affect whether external data can be retrieved.

## 🎓 Project Scope

SkillBridge is an educational web development project intended to demonstrate fundamental web technologies and user-centered interface design.

The website is not a complete recruitment system. It does not guarantee the availability of training opportunities, validate providers, or submit applications on behalf of students.

Sample opportunities are intended for demonstration and educational purposes unless explicitly identified otherwise.

## 👥 Team Contributions

The project is divided into three main development areas:

- **Home Page & API Integration:** Homepage design and development, external API integration, dynamic data presentation, and error handling.
- **Opportunities Page & JSON:** Opportunities interface, JSON-based sample data, search, filtering, and opportunity details.
- **Skills Guide & XML:** Skills guide interface, XML-based skills data, data parsing, and skill categorization.

All sections follow a shared visual identity and navigation structure to maintain consistency across the website.

## 🌱 Future Enhancements

Potential future improvements include:

- Expanding the range of career fields and skill categories.
- Integrating additional reliable data sources.
- Improving opportunity discovery with more advanced filters.
- Adding accessibility and usability enhancements.
- Providing more detailed learning resources for individual skills.
